# Dependencies installed by SageMaker's PyTorch inference container before
# inference.py is imported. Keep this list minimal — torch / torchvision /
# numpy are already present in the base image.
#
# NOTE: `sam3` itself is NOT pip-installed here. This fork lives in a
# private repo (Chevolier/sam3), so `pip install git+https://...` from
# inside the container would need a PAT that would then get baked into
# the S3 tarball — a credential leak.
#
# Instead, the build cell in launch_deploy.ipynb copies the working-tree
# sam3/ package straight into code/sam3/ inside model.tar.gz. SageMaker
# extracts model.tar.gz to /opt/ml/model/ and adds /opt/ml/model/code to
# sys.path, so `from sam3 import ...` in inference.py picks up the
# vendored copy at container boot — no pip, no auth. Any change you push
# to the local sam3/ tree ships on the next build.
#
# These are just sam3's runtime deps that the base image doesn't already
# ship:
einops
pycocotools
huggingface_hub
iopath>=0.1.10
ftfy==6.1.1
regex
timm>=1.0.17
hydra-core
